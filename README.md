# 俄罗斯方块 · Tetris

一个用纯 **HTML + CSS + JavaScript** 写的经典俄罗斯方块小游戏，**单文件、零依赖**，双击 `index.html` 即可开玩。

![预览](https://img.shields.io/badge/纯原生-无依赖-6c8cff) ![License](https://img.shields.io/badge/license-MIT-green)

## ✨ 功能特点

- 🎮 经典 10 × 20 棋盘，7 种方块
- 🎲 **7-bag 随机**算法，方块分布更公平
- 👻 **幽灵方块**预览落点
- 🔄 **暂存（Hold）** 功能，支持方块交换
- 🧱 简易踢墙旋转，靠墙也能转
- ⚡ 等级越高下落越快，软降 / 硬降加分
- 📱 响应式布局，适配桌面与手机，手机端带触屏按钮
- 🎨 霓虹风格 UI，渐变方块与发光按钮

## 🕹️ 操作方式

| 按键 | 功能 |
| --- | --- |
| `←` `→` | 左右移动 |
| `↑` / `X` / `W` | 顺时针旋转 |
| `Z` | 逆时针旋转 |
| `↓` | 软降（每格 +1 分） |
| `空格` | 硬降（每格 +2 分） |
| `C` / `Shift` | 暂存方块 |
| `P` / `Esc` | 暂停 / 继续 |
| `R` | 重新开始 |

手机上可直接使用屏幕下方的触控按钮，或点击「开始游戏」按钮开局。

## 🚀 本地运行

方式一：直接用浏览器打开 `index.html`。

方式二：起一个本地静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 🛠️ 技术实现

- 纯 Canvas 2D 渲染，无任何第三方库
- `requestAnimationFrame` 驱动游戏循环，按时间累加控制下落节奏
- 矩阵表示方块形状，行列旋转 + 多偏移尝试实现踢墙
- 高分屏适配（devicePixelRatio）
- 棋盘尺寸随视口自动缩放，`resize` / `orientationchange` 时重新布局
